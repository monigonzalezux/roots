# Button

Every action in the panel and the store, as a pill.

Use **`btn-m`** for the main action of a view ("Confirmar pago"), **`btn-miel`** for a second strong action, **`btn-o`** for secondary ones, **`btn-bad`** for rejecting or cancelling. Add `btn-sm` in toolbars. One `btn-m` per view.

The consumer provides: a `<button>` (or `<a>`) with `class="btn btn-m"`, a verb-first label, and optionally a leading 18px stroke icon (`.ico`).
