# FlavorStackBar

Bags per flavor in one row, stacked in the flavor colors.

Order is always Piña, Mango, Fresa. Segments are separated by a 2px card-colored gap. Every chart with these colors shows the `.legend`, and the total sits at the right of each row.

The consumer provides: `.stack` of `.srow` (label, `.strack` with `<i class="f-<flavor>">` segments sized in %, `.sv` total), plus a `.legend`.
